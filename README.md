# Piko Magisk Module

KernelSU/Magisk supported modules for [Crimera Piko](https://github.com/crimera/piko) (Instagram, Twitter)

# Why?

Crimera only releases builds for Xitter, while Instagram is neglected

I hate patching the APK on my phone every time

# Downloads

Get the [latest CI release](https://github.com/NullCode1337/piko-magisk-module/releases).

Use [**zygisk-detach**](https://github.com/j-hc/zygisk-detach) to detach Instagram and Twitter from Play Store as you are using magisk modules. 

## If you are having trouble with the classic mount method of the modules
such as,
- **"Reflash needed"** error after reboots
- **"Suspicious mount detected"** warnings from root detector apps

You can consider using [rvmm-zygisk-mount](https://github.com/j-hc/rvmm-zygisk-mount)
